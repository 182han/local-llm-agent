## 三、可直接复制的消息模板

### 3.1 G3-1：分享地图

> 【C4D 进度】SIAS 周边交互式地图出来了 🗺️
>
> **完全本地跑出来的，没调任何云端 API。**
>
> 模型：Gemma 4 E2B / Q4_K_M（`gemma4-e2b-q4km`）
> 运行时：Ollama 0.40.3
> 设备：MacBook Air M4 / 16GB / macOS 26.2
> 实测：**18 tok/s**，首 token 0.20s
>
> 地图 **6 个标记点**，中英双语。**每个标记点带来源徽章**：
> - `gazetteer` = 坐标已跟 OpenStreetMap 核验过
> - `model` = 坐标是模型自己估的
>
> 这次 6/6 都是已核验的（因为它调了我写的 `list_anchors` 工具）。
>
> 有意思的发现：我一开始不给工具，让模型纯靠记忆出坐标，
> 结果 7 个里只有 2 个能核验上，其中"新郑博物馆"**偏了 4.47 公里**，
> 还把"新郑"写成了"辛静"。**2B 模型适合做编排，不适合当知识源。**
>
> 附件：`赵怡涵_C4D_map.html`（单文件，双击就能开，断网也行）

### 3.2 G3-3：求试用

> 【C4D 求试用】有没有同学愿意试一下我的本地 Agent 技能包？
>
> 需要的环境：Mac（Apple Silicon）或 Linux，8GB+ 内存，装了 Ollama。
> **不需要 pip 装任何东西**（纯标准库）。
>
> 三步：
> 1. `python3 scripts/download_model.py --preset e2b-q4km --out /tmp/dl`（约 16 分钟）
> 2. `ollama create gemma4-e2b-q4km -f Modelfile`
> 3. `bash scripts/reproduce.sh`
>
> ⚠️ **如果你跑 Gemma 4 拿到空回复，先看 `教学说明.md` §7 坑 2** ——
> 这个模型默认开推理轨迹，会把 token 预算吃光。加 `"think": false` 就好。
> **我在这上面卡了很久。**
>
> 跑通了/跑不通都欢迎告诉我，我记进提交包的试用反馈表。
