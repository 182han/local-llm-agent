## run_transcript.txt 里有什么

这份实录由 `scripts/make_evidence.py --collect` 生成，包含 9 个部分：

| 节 | 内容 | 对应 `CHALLENGE.md` 的哪项要求 |
|---|---|---|
| 1 | 设备事实（`sw_vers` / `uname` / `sysctl` / `system_profiler` / Python / Ollama 版本） | 要求 ③ |
| 2 | 运行时（`/api/version` / `ollama list` / `/api/ps`） | 要求 ② |
| 3 | 模型详情（`/api/show` 完整 JSON：capabilities / 参数量 / 量化 / 上下文长度） | 要求 ① |
| 4 | **结构化 JSON 路径**运行（对照产物） | 要求 ④ + Agent 能力 |
| 5 | **原生 function calling 路径**运行（**产出交付地图的那一次**） | 要求 ④ + Agent 能力 |
| 6 | **性能实测**（tok/s / TTFT / 内存，附测量命令说明） | 要求 ④ |
| 7 | 地图核验（`inspect_map.py` 逐点列表 + 距离统计） | 地图质量 |
| 8 | 测试结果 | 可复现性 |
| 9 | 结束语 + 待办提醒 | 诚实性 |

**复现这份实录**：

```bash
python3 scripts/make_evidence.py --collect     # 重新采集
python3 scripts/make_evidence.py --render      # 重新渲染 PNG
```
